# How to run the server

## DEFAULT

- After you clone this project, go into the folder and type:
    1. npm init -y
    2. npm install 

## FRONTEND

- Go into terminal and open the frontend folder and type:
    1. npm install
    2. npm run dev

## Backend

- Go into terminal and open the backend folder and type:
    1. npm install
    2. npm run dev

- You didnt need to setup anything, just type it and it will automatically make a database in your mongoDB Compass.
